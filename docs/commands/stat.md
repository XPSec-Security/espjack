# stat

Category: files

Summary: Show a file's type and size

Usage:

```
stat <path>
```

Manual:

```
DESCRIPTION
    Shows whether a path is a file or a directory, and a file's size.

EXAMPLE
    root@espjack# stat /lab1.pcap
      path   /lab1.pcap
      type   file
      size   498310 bytes
```
