# delay

Category: system

Summary: Pause (for scripts/autorun); Ctrl+C skips

Usage:

```
delay <ms>
```

Manual:

```
DESCRIPTION
    Pauses for the given number of milliseconds. Meant for scripts and
    /autorun.txt, to space out steps (e.g. wait after connecting before
    scanning). Ctrl+C skips the wait.

EXAMPLE
    root@espjack# delay 3000
    (waits 3 seconds)
```
